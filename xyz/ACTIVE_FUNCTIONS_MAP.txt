These functions are called during data loading and analysis.

3.1 DATA LOADING & CACHING
──────────────────────────

load_data(selected_ticker, data_path, _data_fingerprint)  [utils.py]
  ✓ @st.cache_data(ttl=300) - Cached 5 minutes
  ✓ ACTIVE: Called by stock_analyzer.py for every stock view

  Execution Path:
    1. Check if local CSV exists (data/processed/{ticker}_processed.csv)
    2. If yes: Load CSV with pd.read_csv()
    3. If no: Fetch live data from yfinance
       └─→ For "NIFTY 50": Fetch ^NSEI
       └─→ For others: yf.download(ticker, period="1y")
    4. Return DataFrame sorted by index


3.2 INDEX & STOCK SNAPSHOTS
────────────────────────────

fetch_index_snapshot()                          [utils.py]
  ✓ @st.cache_data(ttl=600) - Cached 10 minutes
  ✓ ACTIVE: Called by render_home_view()

  Execution Path:
    for each index in INDEX_TICKERS:
      _fetch_single_index(label, symbol)
        └─→ yf.download(symbol, period="1d")
        └─→ Extract Close, compute delta, pct change
    return snapshot dict


fetch_stock_snapshot(symbol: str)               [utils.py]
  ✓ @st.cache_data(ttl=300)

3.3 LSTM MODEL PREDICTION
──────────────────────────

From tabs/lstm_model.py → render_lstm_tab():

  1. Load model:
     joblib.load(SCALER_PATH)
     tf.keras.models.load_model(MODEL_PATH)

  2. Prepare data:
     X_test = np.array([...])  # Last 60 days

  3. Predict:
     predictions = model.predict(X_test)  # Shape: (1, 4) for 4 horizons

  4. Scale back:
     scaler.inverse_transform()

  5. Visualize:
     Plotly chart with predictions + actuals

SECTION 4: SCHEDULED/PIPELINE FUNCTIONS (BATCH EXECUTION)
================================================================================

These functions run on a schedule (daily) or manual trigger, NOT during app views.

4.1 DAILY DATA REFRESH PIPELINE
────────────────────────────────

Entry Point: daily_pipeline.py → main()
  ✓ Called by: run_pipeline.bat (scheduled via Windows Task Scheduler)
  ✓ Frequency: Once per day before market open (6:00 AM)

  Pipeline Steps (Sequential):

  Step 1: Fetch Fresh Market Data
    src/update_data.py → main()
      └─→ update_all_stocks()
          └─→ For each ticker:
              - _update_single_ticker(ticker)
                  └─→ yf.download() latest data
                  └─→ Append to data/raw/{ticker}.csv
              - Check for stale tickers

  Step 2: Calculate Technical Indicators
    src/preprocessor.py → main()
      └─→ process_all_files()
          └─→ For each raw CSV:
              - add_technical_indicators(df)
                  └─→ Compute SMA(20), SMA(50), RSI, MACD, Bollinger Bands
              - Save to data/processed/{ticker}_processed.csv

  Step 3: Generate LSTM Sequences
    src/data_sequencer.py → main()
      └─→ process_and_save_all()
          └─→ For each processed CSV:
              - Load data
              - create_sequences(data, window_size=60, horizons=[1,5,22,88])
              - Save: data/train_data/X_train_{ticker}.npy
                      data/train_data/y_train_{ticker}.npy
                      data/train_data/X_test_{ticker}.npy
                      data/train_data/y_test_{ticker}.npy
              - Save scaler: data/train_data/scaler_{ticker}.pkl

  Step 4: Train LSTM Models
    src/train_model.py → main()
      └─→ train_all()
          └─→ For each X_train_{ticker}.npy:
              - Build model: build_model(input_shape, output_size=4)
              - Train: model.fit(epochs=10, batch_size=32, verbose=0)
              - Save: models/lstm_{ticker}.keras

5.1 SENTIMENT ANALYSIS
──────────────────────

analyze_ticker_sentiment(ticker, max_articles=8, query_type="recent sentiment")
  ✓ File: src/news/sentiment.py
  ✓ WHEN CALLED:
    - Currently: Not integrated into UI (placeholder in news_sentinel.py)
    - Future: render_news_tab() will call this
    - Pipeline: Manual execution via scripts

  Execution Steps:
    1. fetch_ticker_articles(ticker, max_articles)
       └─→ Get verified news articles

    2. NewsRetriever(top_k=8).retrieve(articles, query, recency_days=2)
       └─→ Filter articles by recency
       └─→ Try EmbeddingRetriever (FAISS + sentence-transformers)
       └─→ Fallback to TF-IDF + cosine_similarity
       └─→ Return top_k relevant chunks with scores

    3. Score each article:
       └─→ _finbert_score(text) or _keyword_score(text)
       └─→ Adjust by relevance: score * (0.7 + relevance)
       └─→ Apply source weight (Reuters=1.1, others=1.0)

    4. Aggregate:
       └─→ Weighted mean: sum(score * source_weight * (0.55 + relevance*1.2))
       └─→ Classify label: Bullish/Bearish/Neutral/Risk-off/Mixed

    5. Return:
       {
           "ticker": str,
           "overall_score": float [-1.0, 1.0],
           "label": str,
           "confidence": float,
           "articles": [scored articles],
           "evidence": [attribution records],
           "drivers": [reasons],
           "summary": str
       }


5.2 MARKET CONTEXT BUILDER
──────────────────────────

build_market_context(ticker, horizon=5)
  ✓ File: src/market_context.py
  ✓ WHEN CALLED: Currently unused in UI
  ✓ PURPOSE: Combine technical + sentiment for recommendations

  Execution Steps:
    1. Sentiment signal: analyze_ticker_sentiment(ticker)
    2. Technical signal: _technical_signal(dataframe)
       └─→ trend = (short_momentum + long_momentum) / 4
       └─→ Combined with price trend
    3. Hybrid score: technical * 0.5 + sentiment * 0.5
    4. Label: Bullish (>0.03), Bearish (<-0.03), Neutral
