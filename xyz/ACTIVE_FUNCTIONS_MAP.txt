EQUIMASTER-AI: SOURCE AND FUNCTION MAP
Updated: 19 November 2026

This is a static inventory of maintained application/pipeline modules. It does
not imply that every function is called on every render or has runtime coverage.
Tests, notebooks, the legacy webapp prototype and generated files are separate.

NORMAL EXECUTION FLOWS

1. app.py -> views.home_view.render_home_view: markets, screener and latest news.
2. pages/stock_analyzer.py lazily selects Overview, Technical Chart, LSTM Model,
   News Sentiment or Fundamentals. Quote, history and model-training dates differ.
3. daily_pipeline.main -> pipeline_lock -> run_pipeline -> run_stage subprocesses:
   market refresh, preprocessing, canonical training, evaluation, fundamentals
   refresh and the gated fundamentals-model readiness check.
4. scripts.train_manager.main checks active data/model hashes, fetches at least
   20 fresh verified stories for each ticker needing training, then delegates to
   src.training.train_ticker. Immutable bundles publish through atomic pointers.
5. src.forecast.predict_forecast resolves matching features/scaler/weights and
   returns a direct price path and empirical intervals for 1/5/22/63 sessions.
6. News providers -> publisher/issuer/time filters -> deduplication -> archive ->
   retrieval and sentiment. Hosted LLM synthesis is optional; learned forecast
   fusion and pooled-model work remain separate experiments unless activated.
7. Fundamentals providers -> build_details -> snapshots/history ->
   calculate_fundamental_valuation -> estimate_stock_valuation. The 252-session
   return model remains unavailable until matured point-in-time labels pass gates.
8. Release CLIs: audit_universe, valuation_coverage, validate_runtime,
   evaluate_watchlist, evaluate_cost_sensitivity, evaluate_news, validate_browser,
   export_news_annotation_batch and package_release.
