EQUIMASTER-AI: MAINTAINED PROJECT STRUCTURE
Updated: 19 November 2026

This inventory describes the actual source layout and runtime contracts. Runtime
counts and dated validation belong in PROJECT_STATUS.md and reports/; line counts
and artifact sizes are intentionally not hard-coded.

ROOT
  app.py                    Streamlit markets/screener/news entry point
  config.py                 Configured 58 companies + NIFTY index, horizons and paths
  daily_pipeline.py         Locked, bounded subprocess workflow with incremental status
  run_pipeline.bat          Uses the project .venv Python
  utils.py                  Cached quote and data access for the UI
  README.md                 Setup, operating commands and supported environment
  PROJECT_STATUS.md         Current verified evidence and research limitations
  RELEASE_CHECKLIST.md      Release closure and administrator action
  VALIDATION_PROTOCOL.md    Temporal splits, baselines, intervals and fusion protocol
  FUNDAMENTALS_GUIDE.md     98 supported parameters, provenance and valuation methods
  RAG_BLUEPRINT.md           News/LLM contracts and point-in-time restrictions
  UI_DESIGN.md              Theme, interaction and browser verification
  requirements*.txt        Core lockfile, direct dependencies and optional tools
  .github/workflows/        Windows/Python 3.13 offline CI
  .streamlit/config.toml    Application theme/settings

SOURCE AREAS
  components/               Shared navigation, theme, index quotes and market widgets
  views/                    Home markets/screener/news presentation
  pages/                    Stock analyzer and lazy research navigation
  tabs/                     Overview, technicals, forecasts, news and fundamentals
  src/                      Data, forecasting, artifacts, news, LLM and valuation logic
  scripts/                  Supported CLIs and compatibility entry points
  tests/                    Offline unit and Streamlit interaction regression suite
  assets/                   CSS and shared visual assets
  images/                   Existing project images and dated browser evidence
  reports/release-20261119/  Dated validation copies and model inventory
  xyz/                      Research paper (.txt/.docx), technical report and indexes
  notebooks/                Exploratory work; not the canonical training entry point
  webapp/                   Preserved separate prototype; not the release dashboard

PERSISTENT RUNTIME ARTIFACTS (PRESERVED LOCALLY, EXCLUDED FROM SOURCE GIT TRACKING)
  data/raw/                 Provider OHLCV; older histories are retained on refresh
  data/processed/           Feature CSVs; unchanged active snapshots are retained
  data/train_data/          Legacy/experimental sequence arrays and scalers
  data/fundamentals/        Company snapshots, units, periods, sources and statements
  data/fundamental_history.sqlite3  Point-in-time fundamentals archive
  data/news_cache/          Short-lived current news caches
  data/news_archive/        Timestamped observations for historical retrieval
  data/benchmarks/          Sentiment benchmark provenance and annotation batches
  data/evaluation/          Frozen-model, cost, quality, valuation and inference reports
  models/active_<ticker>.json  Atomic pointer to an immutable active version
  models/versions/<ticker>/<version>/
      metadata.json         Features, dates, hashes, horizons, news gate and metrics
      processed.csv         Exact immutable fitting/evaluation dataset snapshot
      scaler.pkl            Matching training-fitted scaler
      h1/h5/h22/h63.weights.h5  Direct multi-session model weights
      backtest_h*.csv       Chronological test origins, target dates and prices
  models/fundamental_ml/    Return-model artifacts only after maturity/validation gates
  logs/                     Progress, pipeline state, readiness and provider failures

The local release ZIP contains a clean source snapshot plus current bundles and
selected runtime directories. RELEASE_MANIFEST.json records the exact source
commit, model inventory, successful remote CI and per-file checksums. Python
virtual environments, provider cookies and secrets are excluded.
